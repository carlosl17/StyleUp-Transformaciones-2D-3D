# StyleUp — Tarea Semana 10: Transformaciones 2D y 3D

## Consigna
Dos ejercicios de la clase y uno de creación propia. Entregar el enlace de un repositorio GitHub.

## Contenido
1. **01-ejemplo-docente-2d**: adaptación funcional de `https://github.com/hernanpc/transform01` con cuatro cuadros y las transformaciones rotate, translateX, scale y skew.
2. **02-ejemplo-docente-3d**: adaptación funcional de `https://github.com/hernanpc/Transform3d` con un cubo de seis caras en perspectiva.
3. **03-proyecto-propio-styleup**: desarrollo original que usa las dos imágenes proporcionadas por el estudiante: chaqueta azul (vista frontal/posterior) y collage de seis looks. Incluye tarjeta CSS 2D y carrusel CSS 3D, controlados con JavaScript.

Los ejemplos 1 y 2 son versiones adaptadas del código del docente, no reproducciones literales. Se reconoce su autoría y se enlazan las fuentes.

## Ejecutar
Abrir esta carpeta en Visual Studio Code; hacer clic derecho sobre el archivo `index.html` de la raíz y escoger **Open with Live Server**. También puede abrirse directamente en un navegador. No requiere npm, Angular ni conexión a Internet.

## Conceptos
- 2D: `transform: rotate`, `translateX`, `scale`, `skew`; `transition`.
- 3D: `perspective`, `transform-style: preserve-3d`, `rotateY`, `translateZ`, `@keyframes`.
- JavaScript: `addEventListener`, cambios de `element.style.transform` y temporizador del carrusel.

## Entrega
Crear un repositorio público en GitHub y subir el **contenido de esta carpeta**, asegurando que el archivo principal `index.html` quede en la raíz. Entregar solo el enlace al repositorio según instrucciones de la clase.
